# Sound

All effects are from [Kenney](https://kenney.nl)'s CC0 packs — no attribution
required, given anyway.

| file | pack | why this one |
| --- | --- | --- |
| `stone-1/2/3.ogg` | Casino Audio | poker chips on felt. Three of them, because a real set never makes the same noise twice and the ear notices a repeat long before it notices a difference. |
| `capture.ogg` | Casino Audio | chips being swept up — a piece coming off the board. |
| `ui-press.ogg` | Interface Sounds (`click_001`) | the press under every button. |
| `denied.ogg` | Interface Sounds | a square the rules will not take. |
| `win.ogg` | Interface Sounds | the end of a game. One phrase, not a fanfare. |

`bgm.mp3` is **GO with me's** background music, standing in until this game has
its own. It is the one file here that is not Kenney's and not CC0; replacing it
is a drop-in — same name, same folder, and `deploy-preview.sh` already puts the
right content type on it.
