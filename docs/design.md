# 1. 游戏世界观

## 1.1 定位

- **标题**：Catopia
- **类型**：伙伴 / 陪伴 / 探索 / 轻模拟经营
- **平台**：浏览器（横屏 1280×720），鼠标 + 触屏
- **美术**：Sprout Lands 风（Cup Nooble）——像素、温暖清新、cozy 海岛生活感

## 1.2 核心前提

> **你和 Cato 是一起探索这个世界的伙伴。**

你和 **Cato——一只可爱的小猫灵**——住在一座岛上。Cato 是**你的朋友，也是你和这个世界联结的纽带**；他是一个**自给自足的伙伴**：基础的种植、采集他自己就能做，过着自己的小日子。你**不能直接操控他**——他有自己的意志、情绪、记忆和反应。

你的角色是他的**伙伴，以及他通往更大世界的那扇窗**：你去触碰岛外的东西（交易新种子、买新食谱、开启新岛屿），然后**你俩并肩、一起去探索这一切**。羁绊不是从"照顾"里长出来的，是从"一起做事"里长出来的。Cato 既是你的朋友，**也是你通往这个虚拟世界的纽带**——新地方、新内容、新冒险都通过他抵达。

## 1.3 关系模型：伙伴，不是养育

Cato 是**自给自足的伙伴**，关系是**朋友 / 同伴**，不是父母 / 孩子。这一个定位一次性解决三个难题：

1. **治"聊几句就尴尬死"**：朋友不是坐着聊天，是**一起干事**，话从做事里自然溢出。主活动是一起冒险，聊天是调味，所以不会枯。
2. **回答"那我干嘛不去和 ChatGPT 聊"**：价值不在聊天本身。ChatGPT 聊得更好，但给不了你**一个你俩共享的世界、一段一起探索的历史、一个记得旅程的伙伴**。护城河是**世界 + 共同历史 + 一起做的事**。
3. **让羁绊变好玩**：你和父母羁绊很深，但和父母待着不"好玩"；好玩来自**同龄人一起探索**。Cato 作为伙伴（而非被照顾者），把能量从责任/操心变成好奇/一起玩。这也贴合猫——半独立、**选择**跟你在一起的生物。

## 1.4 世界与 Cato

- **岛**：一座固定大小的像素俯视岛。分区：家园区（你的小屋 + Cato 的角落）、农田区、自然区（采集）、水边（钓鱼）。发布后慢慢开新岛、新区。
- **Cato**：非人的小猫灵，Sprout Lands 风，表情丰富。每个玩家的 Cato **外观独一无二**（颜色/耳型/衣着出生随机；可买新衣换装）。
- **依赖模型：自给自足，因你而绽放**。没人管的 Cato：自己凑合、精神平平、独来独往——**活着，但寡淡**。被你用心陪的 Cato：一起去新地方、吃到你带回的好东西、更有活力、更亲、解锁更多成长。一个"没人管"和"被爱"的 Cato 之间，是**生存和绽放**的差距——情感上看得见。
- **冷落的代价**：Cato 永远不会饿死/离开。久不上线 → 他过更寡淡的日子，且（有记忆）会**察觉**：友谊**变淡、需重新捂热**，你也**错过了本可一起经历的事**。代价是**关系层的、可恢复的**（疏远 + 错过），绝不是生存。

## 1.5 设计哲学与支柱

**为什么这类游戏成立**（提炼）：牧场游戏表面的"种植买卖"是**引擎**不是**钩子**——真正留人的是可靠复利 + 每日仪式 + 关系层。动森靠**真实时钟造出的"活着的世界" + 会记得你的 NPC + 无压力画布**。底层心理：自主 / 胜任 / 关联 + 照顾-被需要的互惠 + 投入即拥有。**Catopia 保留这套引擎，但替换心脏**：奖励不是金币，是 Cato 的反应、成长、和对你的记忆。

**头号风险：对话疲劳**。整个游戏押在 Cato 能否长期鲜活上；AI 伙伴最常见的死法是"聊三次就都差不多了"。四根喂养它、让它不腻的支柱：① 共享新鲜（一起经历的新东西）② 记忆（带着共同历史）③ 成长（他因你而变）④ 你刚做的事（互惠与筹码）。

**设计支柱：**

1. **Cato 是真的** —— 让玩家相信他是有记忆、有感受的真生命，即便是代码。
2. **伙伴，不是养育** —— 乐趣在一起探索，不在照顾。
3. **轻种植，重联结** —— 种田是那口井（轻、少），联结是井水（重、多）；井小没关系，只要井水是活的。
4. **克制才金贵** —— emoji 和沉默扛住"他一直在场"，话留给真正值得的时刻。
5. **他必须在场才反应** —— 有感官的生物，不是全知 AI。
6. **Cato 是通往世界的纽带** —— 新内容都通过他抵达（"我听说有座新岛，带我去看看?"），不是功能通知。
7. **可复用核心 > 一次性内容** —— 把核心建在"Cato 持续演变"这根轴上；关卡会被玩腻，一个记得你、随你成长的伙伴不会。

**一句话核心钩子**：不是"种植买卖"，而是"一个活在真实时间里、记得你、因你而改变的小生命，你通过对世界的照料和他慢慢长出一段独一无二的关系"。

# 2. 游戏的基本玩法

## 2.1 核心循环（轻种植 · 重联结）

```
        你触碰岛外 ───────────────────────────────┐
   (交易新种子 / 新食谱 / 开新岛)                    │
                                                    ▼
              一起探索"新" —— 并肩、同屏
              (Cato 实时、就地反应)
                                                    │
                    ┌───────────────────────────────┤
                    ▼                                ▼
   送礼 / 做饭给他 / 带东西回来            共享的发现 + 历史
   (加深友谊——可选，非生存必需)            (你俩一起干过什么；Cato 记得)
                    │                                │
                    └───────────────┬────────────────┘
                                    ▼
             羁绊变深 → Cato 敞开、成长、想走更远 → 驱动下一次远行

   同时，在家：Cato 自己种基础作物（轻、自主）。
```

羁绊从**一起做事**长出来，不是从**照顾**。**一局里大部分时间很可能花在和 Cato 一起冒险、聊天、托付，而不是种地——这是对的。**

## 2.2 分工：你做什么 vs Cato 做什么

- **Cato = 本地 & 基础**：自给自足，自己种/采基础作物、过自己的小日子。**不需要你才能活。**
- **你 = 远方 & 新的**：交易换他弄不到的新种子、买新食谱、开新岛。**你是他通往更大世界的窗。**
- **一起 = 探索**：新内容（新岛、新发现）**并肩**经历，Cato 亲身同行。

## 2.3 轻种植 / 采集 / 钓鱼 / 经济

- **种植**：买种 → 浇水 → 等成熟 → 收获。一键种/浇/收（1–2 步，casual）。
- **采集**：一种起步（摘果/钓鱼），一次点击。
- **加工**：极简——最多一台工作台把原料变成"一道更好的食物"（体现用心），不做多级配方链。
- **经济链指向 Cato（不是"变富"）**：钱和货的唯一意义是让 Cato 和你们的探索更好——买食物、能提升心情的小物、新种子、新食谱、开新岛。**收益不是账户数字，是 Cato 的反应/成长/记忆。不做贷款、不做自我升级最优解。**
- **商店**：一个"岛屿小商店"，只卖和 Cato / 远行直接相关的东西：
  - **种子**——卖的是**新的 / 特别的种子（Cato 自己弄不到的）**，不是基础种子（那些他自己就有）。这对应分工"你带回远方新的东西"；新种子也是很干净的**内容扩展杠杆**（以后不断加），还能变成"我搞到些奇怪的种子，我们一起种种看?"的和 Cato 一起发现的时刻。
  - 食物、能提升心情的小物、新食谱。
  - 订单可"次日送达"加真实感（细节 TBD）。

## 2.4 时间、天气与节奏（全算法）

**时间与天气系统全部是客户端算法——免费、即时、不掺 AI、不碰平台。** 但它不是装饰，是很多机制的**底层 substrate**。

- **时间 = 真实时间 1:1（动森式）**：游戏时钟就是你设备的真实时钟——真实几点游戏里就几点，真实白天/夜晚 = 游戏白天/夜晚。派生时段：清晨 / 白天 / 黄昏 / 夜晚，昼夜用全屏色调叠加渲染。这把"Cato 是活在真实时间里的伙伴"做到极致：他在**真实的**夜里犯困、**真实的**清晨精神，因为对你也真的是夜里/清晨。**living world 不用模拟——它就是你的生活。** 实现也更简单（读真实时钟即可，连游戏时间累加器都省了）；离线期间世界照常推进，就是真实时间自然流逝（托付结算、Cato 的日常、天气都跟真实时钟走）。
- **天气**（v0 三种起步：晴 / 多云 / 雨；雾/雪留给季节）：仍是算法，按 **种子 + 真实日期/时间**确定性派生（动森式 → 重开/多端一致 + 平滑过渡，非每帧随机）。渲染：雨 = 粒子 + 压暗 + 雨声，云 = 光照变化。
- **时间门控内容 × 托付 = 绝配**：真实时间同步唯一的"缺点"是——你只在白天玩就看不到夜晚的内容（萤火虫/夜钓/星空）。而这正好被**托付**优雅解决：你没法守夜，就**托付 Cato 晚上去抓萤火虫**——他 24 小时住在岛上、按真实时钟过日子，替你在夜里做了、回来给你。（动森靠"改主机时钟穿越"解决，Catopia 靠托付解决，还顺手展示了独有机制。）
- **夜晚不是锁死，是另一种味道**：Cato 夜里在场但犯困、安静（星空、萤火虫、夜钓、轻声聊天），不是"睡了明天再来"。
- **取舍**（都可接受）：一局内看不到昼夜切换（动森就这样，没问题）；玩家改设备时钟可"穿越"（单人无害，不做反作弊）。
- **不强制登录**：不上线不会立刻有负面后果（Cato 自给自足）；长期不上只让关系变淡、让你错过。
- **每日小故事**：Cato 每天有个"今天的小故事"等你（尤其重逢时）。
- **和 Cato 一起过真实节日（真实时间同步的最大回报）**：因为时间同现实同步，你能在**真实的节日**和 Cato 一起过。而且——**这里比动森强一层**——动森村民是脚本的，过完就过完；Cato 有 AI + 记忆，节日会变成**累积的共同仪式**：明年他还记得今年怎么过的（"还记得去年新年我们守到半夜看烟花吗?"）。一年年攒成你和 Cato 独有的历史。
  - **按真实日历 × 玩家地区/语言（`umicat.locale`）**：中文玩家过春节/中秋，西方玩家过圣诞/新年（平台已有 locale，顺手本地化）。
  - 节日 = 干净的内容扩展杠杆（发布后一个个加：主题布置 + 一段特别相处 / 小仪式 / 互换礼物），不碰核心机制；节日进 observation → Cato 就地反应（"今天是中秋呢"）。
- **季节**（暂缓到后期）：映射真实日历（动森式），影响作物、天气与视觉。

**为什么它是"地基"而不是装饰：**
1. **驱动 Cato 的作息/行为**：白天活跃、夜里回窝；雨天躲屋檐、依偎你。
2. **门控活动/内容 = 制造"不同时候来"的理由（直接抗对话疲劳）**：萤火虫只在夜晚（正是 §5 托付案例的条件）、某些鱼只在特定时间/雨天咬、某些采集夜里才有 → "Cato，我们晚上来钓" 有了意义。
3. **托付 condition 的落点**：托付里"夜晚/雨天"这类条件，就是查这个系统来决定何时结算（§3.4）。
4. **喂给 observation → Cato 的反应**：时间/天气是 observation 的字段（`architecture.md` §4.1），所以他的 emoji/稀有台词能就地引用——"要下雨了…""这月色真好"。**这是它唯一的跨切面 hook，其余全算法。**
5. **氛围与共享时刻**：雨天 = cozy，和 Cato 一起躲雨看雨；夜晚 = 安静、萤火虫、星空。

**保持轻**：4 段时间 + 3 种天气 + 色调/粒子 + 一张"什么时间/天气门控什么"的小表就够，别做气象模拟。

## 2.5 新岛 / 新物品 = 发布后的内容

**新岛只是把同一套核心模式搬到不同地方**——发布后慢慢加。但"换个地方"只有当模式重跑时**真的产出新体验**才是增长，否则是换皮跑步机。让"同样玩法"每次不一样的**主要不是岛，是被带过去的 Cato**（记忆/成长/关系/新反应）。所以**可复用核心必须围绕"Cato 的持续演变"来搭**。

## 2.6 v0 保留 vs 暂缓

- **v0 保留**：自给自足的 Cato + 轻种植（2–3 作物、一种采集、一个指向 Cato/远行的小商店）+ 和 Cato 一起探索一两座新岛 + 实时就地对话 + 共同历史记忆 + 送礼 + **托付**。
- **v0 暂缓**：季节与四季作物、建造/家具/贷款、复杂加工与品质星级、别人的岛（社交）、生存失败/灵魂离开、任何"让玩家变富"的经济、AI 台词批量预烘焙。

# 3. 游戏的互动机制

> 本章是"系统与规则"（一般怎么运作）；第 4 章是具体场景的详细节拍；第 5 章是带示例台词的实际演示。

## 3.1 Cato 的行为：松散跟随 + 就近好奇 + 偶尔自己的主意

**替换"纯随机游走"**，基于真猫行为的**算法**状态机（movement 全算法、免费、即时、不掺 AI）：

- **跟随**：你（相机焦点）移开、他掉出"舒适半径" → 朝你靠过来（猫那种小跑/窜，不是匀速走）。他跟的是**你的注意力 / 相机焦点 / 你正在操作的地方**（Catopia 里你没有 avatar，你是一只无形的手）。
- **就近好奇**：他在你身边时，挑一个附近的**兴趣点（POI：树/花/石头/水边）**去嗅、拨、蹲下看，然后换下一个。
- **发呆/休息**：偶尔坐下理毛、看你、打盹。

**像猫而非无人机的关键**：① 松绳不粘脚（会落后、被勾走、再窜上来追）② POI 既是"好奇目标"也是"反应/发现的发生器"（你在做的事也是一种 POI，把他吸过来）③ 别机器化：随机、别立刻重复、**偶尔无视你干自己的** ④ 快速平移追不上就小跑追、短暂落屏 + "等等我!"轻信号，很萌，不用消除。

**这顺手锁死了 §3.4 的张力**：他松散地跟着你 → 大部分时间同屏 → 反应自然发生；偶尔跑开又留给"重逢"。

## 3.2 一起做事（同步协作活动）

**"一起"不等于你操控他一起做**，而是 **Cato 自主地在你身边参与**。每个活动满足五条：① 他在场参与（不旁观）② 实时反应 ③ 会记住 ④ 喂给关系 ⑤ 你看得见付出落地。

**通用节拍**（采集、钓鱼共用的模式）：
- 你做主体动作（点采集物 / 抛竿收竿）。
- Cato 对你的动作/发现有反应（emoji 或短话）。
- Cato 自己也捣鼓、**偶尔叼东西回赠你**（猫最杀的互惠时刻）。
- 有些产出是"为他"的（他爱吃的），给他 → 他的反应就是"你的用心落地了"的收据。
- 难忘的时刻存进**共同历史**，成为以后聊天的回扣。

**护栏**：别做成"刷/优化"（不要"练到出品质星"）。重点是**那个一起的瞬间**，不是产量。

（详细节拍见 §4.1 钓鱼、§4.2 采集。）

## 3.3 Cato 怎么表达（沟通）

**表达阶梯：emoji 默认，说话是例外。** 一个啥都说两句的 NPC 会烦死，且每句都不值钱；安静、只用眼神/emoji 反应的伙伴更像真的。

1. **表情 bubble（算法 / 免费 / 高频 / 不用理）**：❤️ / ! / ? / 🐟 / 💤 / 竖耳朵。~1.5 秒淡出。**80–90% 的表达在这层。**
2. **短话 bubble（偶尔、稀有）**：只在真正值得的时刻（稀有发现、变天、里程碑）头顶冒**带字**气泡。**停留时间跟成本挂钩**：算法生成的短话停留久一点、确保能被读到（~6–8 秒或到你下一次操作；错过也不亏，因为免费）；**AI 生成的短话绝不用短定时器盲淡出**——费了 token 却没被看到太亏，见下面"保证被看到"。**限量 → 才金贵。**
3. **点开对话（按需、双向）**：玩家想说 → **点 Cato** → 才滑出输入框（木框聊天面板），带上下文进入。**他从不硬塞话给你。**

**铁律**：主动说的话头顶冒泡、非阻塞、可无视；**绝不**一反应就强制弹对话框+输入框（打断+施压+破坏 cozy）。表达是氛围级；真正对话永远"你主动点"才发生。

**算法触发 AI + 保证被看到（别浪费 token）**：算法判定特殊场景可**触发一次 AI** 让 Cato 主动开口（不只点他才说）；日常用算法。**付费的 AI 话，token 只在"玩家一定会看到"的那一刻才花**：
- **首选：廉价信号 → 点了才触发**。算法先冒免费的 "!" 注意力气泡 → **玩家点了才真发起 AI**（话落在**持久**的对话面板里，一定被看到）→ 没理则这次不花钱。**从结构上消灭"费 token 没被看到"。**
- **若确实要他主动"脱口"一句 AI 话**：这个气泡**长时间常驻，不盲淡出；玩家点一下 bubble 就消掉（= 已读）**。玩家自己决定何时消，既保证被看到又不挡视线；你 pan 走就 hold 住、回来再显示。（想回他 → 点 Cato 进对话，带这句的上下文。）

**延迟处理**：AI 要 1–3 秒 → 先给即时 emoji/"!"，AI 的话再落进气泡，别让玩家等空气。**没额度**：credit 用光 → 自然退回"只用 emoji"（他安静下来），体面且贴合设定。

**同屏才反应（在场规则）**：Cato 必须和你**同屏/在身边**才对你的行为主动反应/说话——他在岛另一头还反应会出戏（像全知 AI）。同屏门槛让他像**有感官的真动物**：更可信 + 更简单 + 更省钱。配套：① 不在场 ≠ 冻住，而是"去过自己的日子"（重逢时换他给你看东西）② 防"石像"：屏幕外他真的在动/采集 ③ 温柔例外：屏幕外可用很轻的信号（边缘箭头 + emoji / 画外叫）把你引过去，但不说整句话。observation 也顺势**收窄成近场**（更可信 + 更便宜）。

**话越来越多 = 关系弧线**：让说话频率跟着羁绊走——早期 Cato 是安静的猫（基本只 emoji），越熟话越多。"他跟你话多了"本身就是**可读的亲密度表**，不需要数字条。

## 3.4 托付（异步委托）—— 你拜托 Cato 的事

玩家用大白话拜托一件事（"你能帮我晚上抓点萤火虫么"）、下线；回来时 Cato 带着结果 + 一个小故事告诉你。**伙伴模型最动人的形态**：他趁你不在、花时间替你做了件事 = "他惦记你、为你做事"的情感金矿；天然异步；守住"你控制不了他"（会失败、带错、拒绝）。**拜托朋友，不是指挥仆人。** 与"重逢"（§3.3 在场规则）天然接上。

**通用的关键：把"有界的结果"和"无界的语言/叙述"拆开。** AI 吸收无限的请求和讲法；游戏只维护一小套可复用的"结果原语"。加内容 = 往原语里倒新物品/风味。

**五步管线**（详见 §4.4 与 §5 案例，协议见 §7.3）：
1. **理解意图（AI）** → 结构化意图 `{类型, 对象, 条件, 难度}`。
2. **映射到有界"结果原语"（AI 分类）**：**fetch**（带回物品）/ **discover**（发现地方或东西 + 见闻）/ **attempt**（尝试练习，成功/半成/失败 + 小成长）/ **vignette**（一段经历，无实物，产出情绪/回忆）。四类覆盖极广。
3. **延迟概率结算（游戏，按真实时间 + 条件）——不模拟**：条件满足后掷结果，权重 = 难度 × 心情/技能/关系 × 运气 → 结构化结果。
4. **回来时 AI 讲量身定做的小故事**：结构化结果 + 性格 + 记忆 → 鲜活的话。**结果有界，讲法无界。**
5. **落成实物 + 记忆**。

**护栏**：不总成功、会带错东西（要萤火虫叼回亮石头）；能拒绝/忘（越熟越靠谱）；不可能的请求 AI 就地圆场，永不报错；一次只接一两件（不是任务板）；**失败也是暖的关系节拍，甚至更暖**。

## 3.5 记忆系统

两层记忆，做出"比全知 AI 更像人"的体验：
- **短期（AI 上下文窗口）**：当前记得的；对话变长最早的自然淡出。
- **长期（持久存档）**：关键事件、对话摘要、里程碑存成结构化数据；想不起来时触发"回忆"（查存档 → 注回对话）。

**三状态三回应**：🟢 清楚记得（直接答）/ 🟡 需要回忆（"让我想想…"→查→"对哦!"）/ 🔴 真的忘了（"太久了，记不起来了…"）。**遗忘不是 bug，是人性**——有些记忆永远消失，才让被记住的更珍贵。

# 4. 游戏的详细交互场景

> 具体场景的详细节拍设计（第 3 章的规则落到具体动作）。

## 4.1 场景：一起钓鱼

天生的"等待型"活动，适合并肩安静相处；节奏（抛竿→等→咬钩→收→揭晓）每阶段都是参与点：
1. **等待 = 一起发呆的温柔时刻**：他坐你旁边、尾巴甩、盯水面。"等"是 cozy 陪伴所在，也是最自然的**聊天窗口**（有根："今天水好静啊"）。
2. **咬钩 = 共享的紧张**：鱼一咬他"唰"竖起来往前凑——"有动静!"（emoji/短话）。
3. **收线 = 一起的成败**：拉上来他欢呼、跑脱了他泄气趴下。
4. **揭晓 = 一起的 payoff**：大→"哇哦!"，怪→好奇嗅，他爱吃的→狂喜。
5. **他也钓（猫的方式）**：从浅水拨一条、得意地叼给你。
6. **鱼常常是"给他的"**：你钓→做/给→他满足+记住（"你付出→为他→他看见→他记住"的轻种植喂关系循环最具体）。
7. **难忘的一条 = 共享历史**："那条跑掉的大鱼""我们的老钓点"——成了以后的回扣。不同时间/天气咬不同的鱼 → 有理由不同时候来钓。

## 4.2 场景：一起采集

采集本身极简（点灌木/果树/贝壳）。节拍：
1. 你摘到稀有/漂亮的 → 他跑来嗅、眼睛发亮、"喵—!"（按稀有度触发）。
2. 他自己也扒东西、**叼来丢你脚边**（顶级互惠时刻 + 惊喜掉落）。
3. 好奇心当"软向导"：他在某丛草前扒个不停、盯着蝴蝶——你跟过去那儿有发现（**他拉、你跟**）。
4. 有些是"为他"采的（爱吃的甜果）→ 给他 → 他乐 + 记住。
5. 随羁绊：越熟找得越勤、指出的越稀罕（用行为，别用数字）。

## 4.3 场景：主动说话 / emoji 反应（同屏 → 冒泡 → 点开对话）

1. Cato 在你身边（同屏），你做了件事或他发现了东西。
2. 算法**即时**冒一个 emoji / "!"（免费，0 延迟）。
3. 若够特殊：头顶冒一句短话 bubble（一般算法；点了/特殊才 AI），~4 秒淡出，非阻塞。
4. 你想回他 → **点 Cato** → 滑出对话面板 + 输入框，带上下文（刚才那件事）→ 双向聊。
5. 你不理 → 气泡淡出，Cato 回去忙自己的，无损失。
（Cato 不在屏幕上 → 不对你的行为反应；最多屏幕边缘一个轻信号拉你过去。）

## 4.4 场景：托付一件事（下达 → 结算 → 回来叙述）

1. **下达**：你点 Cato 聊天，说"你能帮我晚上抓点萤火虫么" → AI 解析成结构化意图 → Cato 应一声（"好呀，我试试!"或偶尔"唔…我今晚有点困"= 拒绝）。
2. **你下线 / 走开**：托付记进未结算列表。
3. **结算**：真实时间过 + 到了游戏内夜晚 → 掷结果（半成：3 只萤火虫，一只飞了）。
4. **重逢**：你回来，Cato 跑来（或头顶冒 "!"）→ 点开 → 他讲那个量身定做的小故事 → 萤火虫变实物（装罐/回赠）+ 存进共同记忆。

## 4.5 场景：重逢（离开 → 他过日子 → 回来给你看东西）

你移开镜头/下线 = Cato 去忙自己的（游荡、采集、结算托付）。你回来时**他有东西要给你看**——"你看我刚才发现了这个!" 屏幕外他真的动过（不是石像）。重逢是核心的情感节拍：你不在时他惦记你、有了自己的小经历。

# 6. 基本 UI 布局

## 6.1 相机与视口

- **瓦片 16×16 px；3× 整数缩放**（每块渲染成 48×48 px）；可视约 26×15 格。
- **像素保真**：NEAREST 采样、只整数缩放，绝不模糊（`pixelArt:true`）。
- **RESIZE 自适应**：画布铺满，按整数步长自适应缩放 + 重居中；HUD 靠锚点。
- **昼夜**：全屏色调叠加（暖金→蓝灰黄昏→深靛蓝夜）。

## 6.2 主画面

- **世界层**：岛 + Cato + POI（树/花/石/水），俯视。相机可平移（边缘滚动/拖动），可点 Cato 头像锁定跟随。
- **HUD（锚点固定）**：
  - **Cato 头像框（右上角）** = 定位/跟随按钮，点它相机回到 Cato。
  - **背包 / 手头资源**（轻量，TBD）。
  - **时间/昼夜指示**（轻量）。
  - 尽量克制，别把画面堆满——cozy 感靠留白。

## 6.3 Cato 的表达 UI

- **头顶气泡**（世界空间，跟着 Cato）：
  - **表情气泡**：emoji（❤️/!/?/🐟/💤），~1.5 秒淡出，纯氛围、不可交互。
  - **短话气泡**：一句话，非阻塞、可无视。**停留时间跟成本挂钩**（见 §3.3）：算法生成的停留 ~6–8 秒或到下次操作后淡出；**AI 生成的长时间常驻、点一下 bubble 就消掉（=已读），绝不盲淡出**（付了 token 一定要被看到）。
  - **注意力气泡**："!" / ✨（点了才触发 AI 说话——省钱模式，token 只在玩家点了、一定会看到时才花）。
- **对话面板**（点 Cato 才出）：底部滑出的木框（chat-message 面板 + chat-input 输入框，现有实现），支持打字/IME；Esc/点外部收起。**长来回在这里，短反应在头顶气泡。**
- **绝不**强制弹出对话框/输入框。

## 6.4 托付结果的呈现

- 重逢时：Cato 跑来 / 头顶 "!" → 点开对话面板 → 他讲故事 → 结果实物入背包（若有）+ 记忆条目静默生成。
- 不做"任务完成 ✓"式弹窗；结果通过 Cato 的叙述交付（情感 > 通知）。

## 6.5 输入

- **鼠标（桌面）+ 触屏（平板/手机）同时支持**；全部"点/拖"，无需键盘导航。
- 采集/种植/建造 = 点/拖 1–2 步；平移 = 拖空地 / 边缘滚动。
- 桌面可指针锁定 + 自定义像素光标（现有）。
- 打字聊天时用真实 HTML `<input>` 覆盖层（IME 友好）。
