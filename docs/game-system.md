# Catopia — 游戏系统

> 具体游戏系统 / 机制清单（玩家侧的"怎么玩"）。与 `design.md`（世界观/情感设计）、`architecture.md`（技术架构）互补。本文档在 Documents 工具里维护。

---

## 信箱

小岛在游戏开始的时候就会有一个信箱，我们订购的东西会在一定时间之后送达到信箱。Catopia 的朋友也会给 Catopia 发送信件——我们以这种信件的交互方式给用户提供 Catopia 的新消息、这个游戏的新动态、新物品等等。

## 种植

- 游戏刚开始时玩家背包里会有一些各种不同的种子可以直接使用。
- 种植流程：先**耕地** → 放**种子** → **浇水**，植物随着每次浇水后过一段时间长大，成熟后就可以**收割**。
- 收割之后这块地又变成已经开垦过的空地，需要重新播种。
- 种子可以从商店购买。
- 一开始进入世界时地上很多**杂草**，需要除掉杂草、开垦地、种农作物。如果农作物收割后没有种下新种子，地上会长杂草；其他草地时间长了也会长杂草。
- 不同的农作物生长速度不一样。

## 制作台

制作工具需要制作台。游戏一开始没有这个，需要花钱购买。有了制作台之后就可以制作各种基础材料、工具，甚至是房屋。

## 工具

游戏开始时工具很简单：

- **水壶**：给农作物浇水，容量很小，水用完后需要到水边去取。（以后可以随意在某个地方打井取水方便）
- **镰刀**：收割庄稼使用。
- **锄头**：耕地使用。
- **斧头**：伐木使用。
- **镐**：敲石头采矿使用。（地上的大石头目前设计成不会消失的，可以一直采矿，但每天采矿量有限制）

Cato 也有自己的一套工具。

## 料理

- 和制作工具一样，料理需要**料理台**，也是游戏初期花钱购买。
- 有了料理台就可以制作料理。买了料理台之后初期只能得到一些**基本料理食谱**，后面可以通过发现探索、和朋友交流等得到更多食谱（具体怎么设计还没想好）。
- 这些料理都是**给 Cato 吃的**。Cato 平常跟你出去都会消耗体力，体力消耗殆尽他基本上就只能很简单地跟你移动，也不会跟你有什么互动了。
- 不同的料理能给 Cato 恢复不同的体力，而且还能增加他跟你的友好度、他的心情指数等等。

## 设施

- 游戏开始时整个地图就是一堆杂草、乱石头、灌木丛、苹果树和草莓丛。我们需要先采集苹果、草莓等基本东西出售获得金钱，然后购买制作台，通过原料制作各种材料：比如砍伐得到的木材做木板、捡到的石头冶炼铁；木板可以做栅栏、房子的地板、窗户、柜子、床等家具；做了柜子可以增加储物空间、存储更多东西。
- 建造房子或任何设施类似 **Minecraft**：你可以随意摆放，也可以随意拆掉。

## 背包

像 Minecraft 一样，用户有一个空间有限的背包，平常需要使用的东西放到背包里；以后到其他岛旅行，需要的东西都只能装在背包里。

## 钓鱼

- 鱼会随机出现，在水里时任何鱼都显示成同样的**影子**，不同种类的鱼随机出现，越稀有的鱼越难钓到。
- 钓鱼方式：玩家在鱼的影子附近抛出鱼竿 → 鱼来试探咬钩 → 如果鱼上方突然出现一个**叹号**就可以收杆。越稀有的鱼越不容易收杆；如果叹号消失前没有收杆，鱼就会游走消失。

## 天气

- **雾天**：容易找到蘑菇。
- **雨天**：容易有很多鱼出现。

## 操作

**Desktop：**
- 键盘上下左右或 WASD 移动 camera；或鼠标到边界也可以移动 camera。
- Tab 调出工具选项。

**Touch screen：**
- 拖拽地图移动 camera。

整个游戏的操作非常类似**一个 2D Minecraft**：选择不同的工具做不同的事情，选择可以摆放的物品摆放在可以摆放的位置，背包打开后显示在屏幕下方一行。

- 例：切换工具成锄头就可以锄地，然后在背包里选择种子，鼠标移动到被锄的地就可以播种（每块地一个种子，直到种子用完或切换成其他可摆放物品），然后再切换到水壶浇水。
- 如果背包里有建造房子的木板、墙壁、门，就可以从背包里点选，然后在地图上摆放。
- 拆东西也像 Minecraft：点选某个可拆东西的工具（比如斧头），连续点某个要拆的物件，就拆掉了。
- 和 Minecraft 不同的是：不是每个建筑物都一块一块建造起来——只有自己的家是这样。像**鸡舍、牛舍是现成的建筑**，只能整体摆放和拆除，因为它们有自己独特的功能，用户单靠搭建没法赋予它们功能（也可以想象成星际争霸里不同建筑有不同功能）。
- 鼠标移到不同的东西上可以切换到相应的工具采集。

## 所有物品和东西

- **树木**：能采集木材，每天只能从同一棵树上砍到 3 个木头，如果继续砍就会把树砍断。要重新种树需要买小树苗。
- **大石头**：可以用镐开采石头原料，每天只能开采 3 个，如果继续开采石头会消失，以后需要一定时间才会重新出现。
- **信箱**：在商店订购的物品每天可以从这里获得；Catopia 世界发生的新闻也可以从这里获得。
- **鸡舍**：能孵出小鸡，小鸡长大成大鸡。点击鸡舍可以看到当前有多少只鸡（可以把鸡卖掉），也可以看到有多少鸡蛋（可以卖掉、采集，或等鸡蛋孵化成小鸡）。
- **牛舍**：能孵出小牛，小牛长大成大牛。点击牛舍可以看到当前有多少牛（可以卖掉），也可以看到有多少牛奶（可以卖掉或采集）。

## Cato

- 基本上跟随相机和鼠标移动，但**不是**鼠标移到哪儿他就一步不差地立马跟上（那样会显得他上蹿下跳）——他大致朝着鼠标的区域移动。
- 如果种下了什么、或采集到了什么，他就到旁边去看看，然后显示表情符号，或在特殊时候显示他的语言。
- Cato 会观察整个小岛的状况，会**提醒你**（有很多玉米成熟了、现在出现了很多鱼）。简单提醒直接在头上显示很简短的文字；很复杂的提醒就在头上显示**叹号**，用户点他后可以显示一长段对话。
- Cato 会**执行用户的指示**：比如用户叫 Cato 去采集木头，Cato 就自己去砍树木采集；用户说去钓鱼，Cato 就自己去钓鱼。
- Cato 有自己的**背包**：用户可以打开自己的背包，把东西（食物、种子等）放到 Cato 的背包里。如果叫 Cato 去种种子，Cato 的背包里必须有这个种子，否则 Cato 就会说"我背包里没有种子"。
- Cato 有**精力条**：精力较少时需要吃东西补充；如果 Cato 背包里有食物，他可以自己吃。

## Cato 执行用户的请求（技术设计）

游戏用算法给 Cato 赋予各种行动能力：采集木头、钓鱼、播种……

**用例 1：玩家叫 Cato 去采集木头**
1. 游戏算法给 AI 发送当前的地图和游戏数据信息，以及 Cato 能执行的操作清单（类似 agent 的 tool）。
2. AI 回复游戏一系列按顺序执行的操作，比如：① 到某个点、砍树；② 到另一个点、砍树。
3. 游戏算法执行完毕后，给 AI 发送一条独立的执行结果。
4. AI 查看操作结果，给游戏返回下一步操作或对话内容。游戏算法根据不同结果继续执行操作或显示对话。

**整体架构**：游戏规定好一系列 Cato 可以执行的**原子操作**；AI 根据当前游戏数据 + 用户消息制定操作计划返回给游戏；游戏算法按顺序执行，返回执行结果给 AI；AI 做下一步指示。
