# Gomoku with me

Five in a row against an engine, with an AI assistant beside the board — and
the template the other board games in this family fork.

```bash
npm install
npm run dev
npm run verify   # the referee's own tests
```

`src/shell/` is shared machinery and is not meant to be edited; `src/game/` is
the game. `CLAUDE.md` is the working memory of this repo: read it first.
